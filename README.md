# Simple E-Commerce Header

A beginner-friendly, clean retail header built with HTML5, CSS3, and Vanilla JavaScript. Includes a rotating announcement bar, responsive search layout, auto-collapsing categories, and a fully functional sliding mini-cart.

## Features
- **No Frameworks:** Built entirely with plain HTML, CSS, and JS.
- **Announcement Bar:** Rotating promotional messages that remember if you closed them (localStorage).
- **Responsive Layout:** Search bar breaks to a new line on mobile, and categories become a horizontal scrollable strip.
- **Smart Categories:** On desktop, if the categories don't fit the screen, they automatically move into a "More" dropdown.
- **Interactive Mini-Cart:** Change quantities, remove items, and see the subtotal recalculate automatically. On mobile devices under 600px, it converts into a bottom-sheet drawer.
- **Accessible:** Includes ARIA attributes, focus trapping inside the cart, and Escape-key closure.
